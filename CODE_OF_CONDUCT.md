# Code of Conduct

## Our standard

We want participation in this project to be professional, respectful and free of harassment.

Expected behaviour:

- Be respectful and constructive in issues, pull requests and discussions.
- Give and accept technical feedback graciously.
- Focus on what is best for the project and its users.

Unacceptable behaviour:

- Harassment, personal attacks, insults or discriminatory language.
- Publishing others' private information without permission.
- Any conduct that would be inappropriate in a professional setting.

## Enforcement

Maintainers may edit, remove or reject comments, commits and issues that do not follow this code, and may restrict participation of anyone who repeatedly violates it. Report concerns to the maintainer through a private GitHub security advisory or the contact listed on the maintainer's profile.

This code of conduct applies within project spaces and when representing the project in public.
