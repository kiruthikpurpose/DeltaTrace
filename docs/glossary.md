# Glossary

| Term | Meaning |
|---|---|
| Alarm flood | More than ten alarms in ten minutes (ISA-18.2, EEMUA 191) |
| Advisory | A low-trust alarm moved out of the operator list but kept visible and retrievable |
| BAD / UNCERTAIN / GOOD | Trust classes of a channel |
| Chattering | An alarm that repeatedly activates and clears |
| Clock tolerance | Allowance for timestamp differences between RTUs |
| Corroboration | Trust-weighted agreement of neighbouring sensors with an alarm |
| Deadband | Margin an alarm must clear before it resets |
| Delay window | Maximum time gap at which two alarms can belong to one pressure wave |
| Fail-open | With the engine off or failed, raw alarms pass through unchanged |
| FT | Flow transmitter |
| Hop | One node step along the pipeline |
| Incident | A group of related alarms presented as a single item |
| On-delay | Time a condition must persist before an alarm is raised |
| Pareto front | Candidates for which no other candidate is better on every measure |
| PT | Pressure transmitter |
| ROC | Rate-of-change alarm |
| RTU | Remote terminal unit at a station |
| SCADA | Supervisory control and data acquisition |
| Trust | A score from 0 to 1 of how far a sensor reading can be believed |
| Wave speed | Speed of a pressure wave along the line (default 1000 m/s) |
