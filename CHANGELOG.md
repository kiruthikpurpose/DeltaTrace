# Changelog

All notable changes to this project are documented here.

## [Unreleased]

### Fixed
- Operator labels (dispositions) were looked up by incident number, which restarts at INC-001 every run, so an old label could appear on a new, unrelated incident. The detail view now shows the live incident's own label.
- Corrupted or outdated saved data in the browser could stop the app from starting. Saved settings, seed and logs are now validated key by key and fall back to defaults.
- Actions taken during a replay (injecting a fault, approving a setting, labelling an incident, changing settings) went into the temporary replay copy and were lost. They now end the replay and apply to the live run. Resetting during a replay also restores the previous speed.
- The simulation loop could start twice (double speed) if the launch screen finished after the start-up fallback timer.
- Guided Demo could skip a step at high speed because the step advance ran inside a state update.
- Single-key shortcuts fired behind modal dialogs; holding a key repeated fault injections.
- Selecting an incident on the Incidents page made the Live Console open its incident drawer on arrival.
- The replay banner updated the store while rendering.
- Smooth-time animation could run up to 30 s ahead of the engine on slow devices.
- PDF file names used the UTC date, which is a day off near midnight in many time zones.

### Changed
- Project named "DeltaTrace: Trust-Aware Alarm Grouping and Tuning for Pipelines"; README gains motivation, applications and roadmap sections.

### Added
- New identity: alarm streams that merge, pass a trust gauge and end as one incident. A rich app icon (`public/app-icon.svg`) and a flat product mark used in the sidebar, favicon and README.
- Launch animation docks the mark smoothly (compositor-driven flight with a cross-fade hand-off) and adapts to phones.
- Flat linear meters replace the semicircle and ring gauges; pipeline labels size to their text.
- The wordmark now travels with the mark and becomes the sidebar text, instead of two names fading in and out.
- Launch screen (dark, on every page load): amber alarm dots converge into streams and one incident, the drawing simplifies into the mark, and the mark flies into the sidebar logo. Click or any key skips it; disabled under reduced motion; falls back to a fade where the sidebar logo is not visible.
- Apache 2.0 license, contribution guide, code of conduct and security policy.
- GitHub Actions workflow running typecheck, lint, tests, build and a bundle-size check on Node 18, 20 and 22.
- README diagrams as light and dark SVG, generated by `npm run diagrams`.

## [1.0.0]

### Added
- Simulation engine: hydraulic transients, sensor faults and attacks, baseline SCADA alarms.
- Trust engine, delay-based incident grouping with classification and origin estimate, trust-gated replay tuner.
- Live console, incidents, trust center, alarm tuner, write-back and audit, benchmarks, guided demo, how-it-works and settings pages.
- PDF reports for benchmarks, operations and audit, incidents and tuning.
- Light and dark themes, responsive layouts from 320 px, keyboard shortcuts and command palette.
